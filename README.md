## 🌟 Key Features

- **🎯 Precision Navigation**: High-quality Turn-by-Turn (TBT) instructions sent directly to your bike's display using the powerful Mappls (MapmyIndia) engine.
- **📊 Real-time Dashboard**: Monitor your Odometer, Fuel level, Gear position, and Trip data in a sleek, modern interface.
- **🔄 Seamless Connectivity**: Automatic reconnection and stable BLE communication designed for long rides.
- **🛠 Hardware Optimized**: Custom logic for AS, BS, and BM clusters ensuring your turn icons and distances are always accurate.
- **🔓 Fully Open Source**: No tracking, no hidden fees. Just code and community.

## 🚀 Getting Started

Build your own version of SConnect in minutes:

1. **Clone**: `git clone https://github.com/CommitAndQuit/s-connect.git`
2. **Open**: Import the `app` folder into Android Studio.
3. **Run**: Connect your Android device and hit building!
